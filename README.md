# tinyApp

TinyApp is a Lighthouse Labs bootcamp project.
It is a link shortener featuring:
- hashed passwords
- session cookies
- method override to allow PUT and DELETE requests


Default Usage:

List of user's links:
HTTP://localhost:8080/urls

New URL:
.../urls/new

Show Link info:
.../urls/id

Link Redirector
.../u/id

Login Page:
.../login

Registration Page:
.../register
